# نظام متابعة المناديب – قسم البيض (القرية)

نظام ميداني لمناديب قسم البيض: تقارير الزيارات بالصور، وقراءة الرف بالذكاء الاصطناعي، ولوحة متابعة للمدير، وطلبات الشراء (PO)، وخط سير الشاحنات.

## طريقتين للتشغيل
1. **تطبيق مستقل (GitHub Pages + Supabase)**: الملفات في جذر المستودع (`index.html`, `runtime.js`, `config.js`). دخول باسم مستخدم وكلمة مرور، ويُثبَّت على الجوال بأيقونة القرية. خطوات النشر في **`دليل_النشر.md`**.
2. **داخل Claude**: نسخة Artifact على claude.ai
   https://claude.ai/artifact/EA4XspUSmBoXMpZE9evkcw
   مصدرها في `claude-artifact/app.html`.

نفس كود الواجهة في النسختين. ملف `runtime.js` يوفّر للنسخة المستقلة قاعدة البيانات والدخول والصور والذكاء الاصطناعي عبر Supabase.

## التوثيق والأدوات
- `docs/سجل_المشروع.md`: سجل كامل للمحادثات والقرارات وما تم وما بقي.
- `CLAUDE.md`: تعليمات لأي جلسة Claude قادمة على هذا المستودع.
- `tools/build_standalone.py`: يبني `index.html` من `claude-artifact/app.html` بعد أي تعديل.

## ملفات Supabase
- `supabase/1_schema.sql`: الجدول، الصلاحيات (RLS)، تخزين الصور، وتعيين المدير.
- `supabase/2_branches.sql`: المناطق الخمس و257 فرع.
- `supabase/functions/shelf-ai/index.ts`: دالة قراءة صور الرف بالذكاء الاصطناعي (Claude). المفتاح يُحفظ كسرّ في Supabase وليس في الكود.

## الأدوار
| الدور | الصلاحية في مشاركة الصفحة | يشوف |
|---|---|---|
| المدير | Editor (في نسخة Claude) / اسم المستخدم المحدد في `1_schema.sql` (في النسخة المستقلة) | كل الصفحات: لوحة المتابعة، أداء الفريق، الزيارات، المتابعة، الأسعار، طلبات الشراء، الرحلات، المناطق والفروع، الفريق، الإعدادات |
| مشرف المنطقة | Contributor / يعتمده المدير | لوحة المتابعة وأداء الفريق لمناديبه ومنطقته، طلبات الشراء، الرحلات |
| المندوب | Contributor / يعتمده المدير | تقرير اليوم، سجله، طلبات الشراء والشاحنات لفروعه، حسابه ومشرفه |

## قاعدة البيانات (المجموعات)
- `profiles/{uid}` بيانات الموظف (يكتبها بنفسه)
- `roles/{uid}` الدور، الاعتماد، المشرف، الموقع (يكتبها المدير)
- `regions`, `branches`, `trucks`, `settings/lists` (يكتبها المدير)
- `reports/{date}_{uid}` تقرير المندوب اليومي وزياراته
- `followups`, `pos`, `trips`
