# نظام متابعة المناديب – قسم البيض (القرية)

نظام ميداني لمناديب قسم البيض: تقارير الزيارات بالصور، وقراءة الرف بالذكاء الاصطناعي، ولوحة متابعة للمدير، وطلبات الشراء (PO)، وخط سير الشاحنات.

## رابط التشغيل
النظام يشتغل كصفحة Artifact على claude.ai، لأن قاعدة البيانات وتسجيل الدخول ورفع الصور والذكاء الاصطناعي كلها من خدمات claude.ai:

https://claude.ai/artifact/EA4XspUSmBoXMpZE9evkcw

> ملف `app.html` هنا هو الكود المصدري للنسخة المنشورة. فتحه مباشرة من GitHub Pages أو من الجهاز يعرض شاشة «افتح الصفحة بحسابك» فقط، لأنه يحتاج بيئة claude.ai.

## الأدوار
| الدور | الصلاحية في مشاركة الصفحة | يشوف |
|---|---|---|
| المدير | Editor | كل الصفحات: لوحة المتابعة، أداء الفريق، الزيارات، المتابعة، الأسعار، طلبات الشراء، الرحلات، المناطق والفروع، الفريق، الإعدادات |
| مشرف المنطقة | Contributor | لوحة المتابعة وأداء الفريق لمناديبه ومنطقته، طلبات الشراء، الرحلات |
| المندوب | Contributor | تقرير اليوم، سجله، طلبات الشراء والشاحنات لفروعه، حسابه ومشرفه |

## قاعدة البيانات (المجموعات)
- `profiles/{uid}` بيانات الموظف (يكتبها بنفسه)
- `roles/{uid}` الدور، الاعتماد، المشرف، الموقع (يكتبها المدير)
- `regions`, `branches`, `trucks`, `settings/lists` (يكتبها المدير)
- `reports/{date}_{uid}` تقرير المندوب اليومي وزياراته
- `followups`, `pos`, `trips`
